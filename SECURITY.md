# Sicurezza

Se trovi una vulnerabilità in DR.KAOS WP THEME, **non aprire una issue pubblica**.
Usa la segnalazione privata di GitHub (scheda *Security* → *Report a vulnerability*)
descrivendo il problema e i passaggi per riprodurlo. Riceverai una risposta appena possibile.

Versioni supportate: l'ultima release pubblicata.
