Tema leggero e vuoto per Elementor, by DR.KAOS.

== Description ==
Nessun stile imposto, nessuna dipendenza. Supporta le Theme Locations di Elementor Pro (header, footer, single, archive), WooCommerce, menu, logo personalizzato, traduzioni e accessibilità.

== Installazione ==
1. Aspetto > Temi > Aggiungi nuovo > Carica tema, seleziona drkaos-wp-theme.zip
2. Attiva il tema
3. Installa Elementor e costruisci header, footer e pagine.
